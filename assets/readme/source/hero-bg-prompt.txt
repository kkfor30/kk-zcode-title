【用途】GitHub 开发者工具 README 的首屏 hero 背景板（会被压在文字与 UI 卡片下面，请当成"材质"而不是"插画"）

【画面】一张宽幅 3:2（1536×1024）的抽象背景板。内容是一间深夜房间里、代码编辑器屏幕发出的环境光，被极度虚化：隐约的竖直线条光带暗示成排的代码行，画面左中部有一团冷蓝色光的漫射晕开，右下角有一小簇温暖的琥珀色微光。远景只有极其轻微的细网格质感，几乎不可辨认。

【气质】安静、冷峻、有夜间纵深感的电影质感。不要热闹，不要霓虹泛滥，不要赛博朋克城市。

【必须主导的配色】近黑的深海军蓝 #0A0D14 作为底色与主调；冷蓝 #4D8DFF 作为主要光源色；少量暖琥珀 #FFB454 作为点缀；其余为中性灰。

【硬性约束】
- 绝对不要出现任何文字、字母、数字、logo、水印、可辨认的界面元素、图标或人物。
- 所有元素都必须是虚化柔和的，不要任何锐利清晰的物体或轮廓。
- 画面左侧居中区域必须保持暗且空旷（文字会压在这个位置）。
- 整体对比度要低、要均匀，保证叠加白色文字后仍然清晰可读。
- 四个边角要有暗角压暗。
- 不要边框、不要画框、不要任何设备或样机的形状。
- 不要给画面加"标题栏""分栏"之类的结构。

【输出】1536×1024 PNG。
