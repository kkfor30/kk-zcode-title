【用途】开发者工具 GitHub README 中，表示"12 个话题类别"的一组三维图标

【画面】一张图里包含恰好 12 个三维图标物件，按 4 列 × 3 行 的严格网格排布，平铺在统一的深色背景上。

【12 个物件，严格按阅读顺序（先左到右，再上到下，一行一行来）】

第 1 行：
1. 🎬 电影场记板（打板）
2. 🔧 一把扳手
3. 🐛 一只小虫子 / 毛毛虫
4. 🚀 一枚火箭

第 2 行：
5. 📊 柱状图（三根高低不同的柱子立在底座上）
6. 🌐 带经纬线的地球仪 / 网络球体
7. 🔎 放大镜
8. 🎨 画家调色板与一支画笔

第 3 行：
9. 📝 便签纸与铅笔
10. 📅 日历（翻开的一页）
11. ⚙️ 单个齿轮
12. 💬 圆形对话气泡

【风格】每个物件都渲染成精致、略带半透明感的磨砂玻璃与拉丝金属质感的三维图标。柔和影棚光从左上打来，边缘有一圈细腻的轮廓光，轻微的景深虚化，物件下方有一层柔和的接触辉光。12 个物件必须在尺寸、材质、打光、视角上完全一致，看起来像同一套图标库。现代、克制、高级——不要卡通感，不要贴纸感，不要扁平化。

【配色】近黑的深海军蓝 #0A0D14 背景；冷蓝 #4D8DFF 作为主光；少量暖琥珀 #FFB454 作为点缀；金属部分为中性银。

【排版约束】
- 恰好 12 个物件，不多不少，不合并、不省略。
- 4 列 × 3 行，间距完全均匀，四边留出等量且充裕的边距。
- 任何物件都不得贴到画面边缘，也不得与相邻物件接触或重叠。
- 每个物件都居中在自己的假想格子里，每个格子大小一致。
- 背景必须平整、均匀、极深，不要渐变、不要暗角、不要纹理、不要地平线、不要环境倒影。

【硬性约束】
- 绝对不能出现文字、字母、数字、水印、标签、说明、界面元素。
- 不要额外的装饰粒子、星光或漂浮的小形状。
- 不要把物件画成扁平的表情符号字形，必须读起来像真实的三维物件。
- 不要出现人物、手、脸。
- 12 个物件不要有任何一个风格跑偏（比如突然变成写实照片或线框图标）。

【输出】1536×1024 PNG。
