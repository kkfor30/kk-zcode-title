【用途】开发者工具 GitHub README 中，表示"话题类别 emoji 系统"的一组三维图标

【画面】一张图里包含恰好 8 个三维图标物件，按 4 列 × 2 行 的严格网格排布，平铺在统一的深色背景上。

【8 个物件，严格按阅读顺序（先左到右，再上到下）】
1. 🎬 电影场记板（打板）
2. 🧩 一块单片拼图
3. 🔎 放大镜
4. 🎨 画家调色板与画笔
5. 📝 便签纸与铅笔
6. 📅 日历（一页）
7. ⚙️ 单个齿轮
8. 💬 圆形对话气泡

【风格】每个物件都渲染成精致、略带半透明感的磨砂玻璃与拉丝金属质感的三维图标。柔和影棚光从左上打来，边缘有一圈细腻的轮廓光，轻微的景深虚化，物件下方有一层柔和的接触辉光。8 个物件必须在尺寸、材质、打光、视角上完全一致。现代、克制、高级——不要卡通感，不要贴纸感，不要扁平化。

【配色】近黑的深海军蓝 #0A0D14 背景；冷蓝 #4D8DFF 作为主光；少量暖琥珀 #FFB454 作为点缀；金属部分为中性银。

【排版约束】
- 恰好 8 个物件，不多不少。
- 间距完全均匀，四边留出等量且充裕的边距，任何物件都不得贴到画面边缘或彼此接触。
- 每个物件都居中在自己的假想格子里，绝对不允许重叠。
- 背景必须平整、均匀、极深，不要渐变、不要暗角、不要纹理、不要地平线、不要环境倒影。

【硬性约束】
- 绝对不能出现文字、字母、数字、水印、标签、说明、界面元素。
- 不要额外的装饰粒子、星光或漂浮的小形状。
- 不要把物件画成扁平的表情符号字形，必须读起来像真实的三维物件。
- 不要把 8 个物件画成同一材质但不同风格的混搭，必须像同一套图标库。

【输出】1536×1024 PNG，2:3 横向。
