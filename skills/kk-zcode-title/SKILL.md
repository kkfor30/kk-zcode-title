# kk-zcode-title

管理后台命名流程。主对话负责用户明确请求的设置与操作；自动命名由独立的 Stop Hook 派生的后台 Worker 执行。

## 定位入口

执行本 Skill 内的 `scripts/run.py`。该入口会定位插件的后台程序。本文件向上两级是插件根目录。

下面的 `<入口>` 表示该脚本的绝对路径，`<话题 ID>` 来自 `status`、审计日志或用户提供的 sess_ 开头标识，不能猜测。

## 检查与配置

1. 执行 `python <入口> doctor`，检查 Python、会话库读取与模型配置；提供话题时追加 `--thread <话题 ID>` 验证读取。
2. **首次使用（初始化向导）**：执行 `python <入口> setup`，插件会自动检测 ZCode 已接入的模型厂商（读取其明文 API key 与协议），为每个厂商启发式挑选 flash/turbo 等轻量档模型并真实调用一次微型请求验证可用性。把检测报告展示给用户，请用户确认选择哪些厂商及优先顺序；额度耗尽时链上下一家自动接管，失败厂商冷却 30 分钟后恢复。
3. 用户确认后按优先级写入：`setup --use <厂商1> --use <厂商2>`（可重复 `--use` 组成 fallback 链；`--model` 可覆盖单个厂商的推荐模型）。写入前会再次真实测试，失败不落盘。
4. 手动指定接口时也可用 `configure --model <模型> --base-url <地址> --api-key <密钥>`（OpenAI 兼容或 anthropic 协议）。
5. `status` 查看配置位置与已记录话题数量（密钥显示为 ***）。

Hook 注册状态在 `doctor` 的 `hook` 字段；`ready` 表示插件已注册启用。ZCode 需要重启后新注册的插件 Hook 才会挂载。`doctor` 成功不能证明 Hook 已自动触发，以审计日志（数据目录 `logs/`）为准。

## 自然语言调整

用户用自然语言提出以下诉求时，直接代为执行对应命令，不额外消耗模型：

- 「换命名模型 / 用 deepseek / 加一个兜底厂商」→ 重新执行 `setup`（检测）+ `setup --use ...`（写入）
- 「暂停自动命名 / 恢复自动命名」→ `pause` / `resume`
- 「这个话题标题固定住」→ `lock <话题 ID>`；「恢复自动命名」→ `unlock <话题 ID>`

## 改名与预览

1. 执行 `python <入口> rename <话题 ID>`，由独立模型生成预览。
2. 用户已经要求改名时，直接执行同一命令并追加 `--apply`；预览请求停在候选结果。
3. 读取命令结果；`renamed` 表示标题元数据已写入且读回核验，`kept` 或 `unchanged` 表示保留。桌面列表若仍显示旧标题，重启 ZCode 或切换会话列表后确认；不要直接修改会话库以外的桌面状态。

`locked` 或 `manual_title` 表示标题受保护。只有用户要求恢复自动命名或覆盖手动标题时，才执行 `unlock <话题 ID>` 后重试。

`stale_result` 表示对话在评估期间已更新，本次候选已丢弃。用户要立即更新时可重新执行。

`ambiguous_title` 表示候选与已记录任务重名，本次保留原名。可以请用户补充具体对象，再重试。

## 暂停与保护

- `pause`：暂停自动命名；正在生成的结果会在写入前再次检查暂停状态。
- `resume`：恢复后续轮次的自动命名。
- `lock <话题 ID>`：固定该话题当前标题。
- `unlock <话题 ID>`：重新允许该话题自动命名。

第一次接触话题时，插件无法判断现有标题是否来自用户手动设置或 ZCode 内置生成。对需永久保留的历史标题使用 `lock`。

## 归档说明

闲置归档功能暂未迁移到 ZCode 版；相关命令当前不可用。ZCode 会话库的 `session.time_archived` 字段已确认存在，后续版本再启用。

## 失败处理

命令失败时保留原标题，先处理 `doctor` 报告的问题（会话库不可读、模型未配置、网络错误），再重试。不要向话题发送改名指令，不让主 Agent 接管后台命名循环。

后台日志仅记录状态、标题和用量，不保留完整对话。日志与配置位于 `status` 返回的数据目录（默认 `~/.zcode/kk-zcode-title`）；诊断时只读取相关话题的记录。排查 Hook 派生问题时可设置环境变量 `KK_ZCODE_TITLE_DEBUG=<日志路径>` 捕获 Worker 堆栈。
